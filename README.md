# 🧾 Tip Calculator

![Tip calculator concept](https://images.unsplash.com/photo-1556740749-887f6717d7e4?auto=format&fit=crop&w=1200&q=80)

A lightweight tip calculator built using HTML, CSS, and JavaScript. It helps users calculate bills, add tips, and split amounts quickly.

## 🌟 Overview

The project is a beginner-friendly front-end app that demonstrates input handling, arithmetic logic, and dynamic content updates in the browser.

## ✨ Features

- 💰 Calculates tip amount
- 🧮 Shows total bill including tip
- 👥 Can be extended for splitting bills
- 🎨 Clean and modern design
- 📱 Responsive user interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📁 Project Structure

Tip_calculater/

## ▶️ Run the Project

Open `index.html` directly in a browser or use:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

- JavaScript calculations
